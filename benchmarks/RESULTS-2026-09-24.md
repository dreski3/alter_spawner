Median matched latency versus cloud direct was 2.91 s higher for attached
OpenCode and 3.47 s higher for fresh OpenCode. Both added about $0.000024
per call in estimated API cost. The strict JSON extraction cases failed across
all four conditions because the models returned fenced JSON. The frozen 80%
harness success and 70% automatic quality targets were therefore missed
(66.7% and 60%). Keep that failure for refinement in roadmap 4.4.

Candidate policy replay selected cloud direct for all 12 ordered calls and
local direct for all 12 lowest-cost calls. Laya also selected local for all
12; it added 0.71 s median routing time and did not improve measured quality.
The replay reuses observed model answers and one measured adviser decision per
task, so its latency is an estimate rather than an independently executed
policy run.

On seven labeled network signals, Laya made seven valid choices and one
wrong route: it sent the held-out team-plan request to technical support.
The fixed keyword classifier made six valid choices and rejected the held-out
canary signal, also yielding one wrong or missing route. Laya's median adviser
time was 0.44 s; the classifier's was 0.000068 s. Both preserved payload
isolation on all seven cases. The separate six scripted invalid, error, and
timeout cases passed their configured fallback or fail-closed expectations
with zero payload isolation failures.

The deep nested fixture matrix passed all eight chain and branch cases at
depths 1, 2, 4, and 8. The depth-8 chain reached nine nodes. The depth-8
branch reached 17 nodes and 18 attempts, including one retry and one planned
terminal failure; its root wall time was 755 ms. The retained raw runs record
queue and admission time, attempts, tokens, and failures at every depth.
These are deterministic Alter fixtures, so they measure tree accounting and
admission behavior rather than model quality in a 17-node network.

The price assumption is $0.10 per million input and output tokens for Mistral;
its uncatalogued cache-read tokens are conservatively charged at the input
rate. Ollama has zero API price, excluding local electricity and hardware.
